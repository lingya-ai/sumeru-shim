# Contributing

Thanks for your interest in Sumeru.

## License of contributions

Sumeru Community Edition is source-available under the PolyForm Noncommercial
License 1.0.0. To keep the project able to offer commercial licenses, **all
contributions require a signed Contributor License Agreement (CLA)** before they
can be merged. See [CLA.md](CLA.md).

If you cannot agree to the CLA, please open an issue or discussion instead of a
pull request.

## Development

- Node.js 22+ for tests/CLI.
- Run `npm run ci` before submitting (tests + syntax + secret scan + compose).
- Keep commits focused; describe the user-visible effect.
- Do not add dependencies without discussion.
- Do not commit `build/`, `dist/`, browser profiles, cookies, tokens or logs.

## Security

Do not report vulnerabilities in public issues. Follow [docs/security.md](docs/security.md).
